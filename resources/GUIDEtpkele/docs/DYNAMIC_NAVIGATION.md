# Dynamic ON THIS PAGE Navigation

Requirement:

The left floating navigation is NOT manually fixed.

The system should:
1. Read article H2/H3 headings automatically.
2. Generate navigation items.
3. Detect current viewport position.
4. Highlight the active section.
5. Move the highlight slider automatically.

Behavior:

User scrolls to:
"Breaking Capacity"

The navigation highlight automatically moves to:
Breaking Capacity

This is similar to professional engineering documentation websites.
