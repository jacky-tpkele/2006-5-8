# TPKELE Technical Guide System — Complete Final Package

This is a complete GitHub + Vercel ready module package prepared for integrating a full **TPKELE Technical Guide System** into your existing website.

## What is included

### 1) Complete technical guide system structure
- `app/guides/[slug]/page.tsx`
- `app/technical-guide/page.tsx`
- `app/market-access/page.tsx`
- reusable components
- guide data layer
- brand CSS

### 2) Ten complete technical guide templates
1. DC MCB Selection Guide for Solar PV Systems
2. DC SPD Selection Guide for PV Surge Protection
3. ATS Selection Guide for Backup Power and Critical Loads
4. AC MCB Selection Guide for Building and Industrial Circuits
5. Voltage Protector Selection Guide
6. DIN Rail Energy Meter Selection Guide
7. PV Combiner Box Selection Guide
8. DC Isolator Selection Guide
9. RCCB and RCBO Selection Guide
10. Solar PV Protection System Guide

### 3) Market Access Advisor connection
Every guide includes a CTA entry that links readers into the Market Access Advisor with the correct product and application prefilled.

### 4) Current website navigation fit
This package is prepared around the current TPKELE navigation logic:
- Products
- Solutions
- Technical Guide
- Market Access
- Support
- About
- Contact Us

### 5) Included image assets
Every article includes matching local image files inside:
- `public/images/guides/<slug>/hero.png`
- `public/images/guides/<slug>/figure.png`
- `public/images/guides/<slug>/quick-flow.png`
- `public/images/guides/<slug>/related-grid.png`

## Important integration notes
- This is **not** a plain static one-page HTML output.
- This package is designed to be merged into your existing GitHub + Vercel website project.
- Keep your own global header, footer, SEO and language system.
- Keep the green TPKELE visual direction.
- Do not replace local image paths with remote links.
