📋 提交步骤（Google Search Console）
=================================================================

方法 1：自动提交（推荐，最快）
-------------------------------
1. 登录 Google Search Console: https://search.google.com/search-console
2. 选择 "www.tpkele.com" 资源
3. 左侧菜单 → 点击 "Sitemaps"
4. 输入: sitemap.xml
5. 点击 "提交"
6. 等待 Google 自动爬取所有页面（通常 1-3 天）

方法 2：手动单独提交（加速特定页面）
-------------------------------
1. 登录 Google Search Console
2. 顶部搜索框 → 粘贴上面的 URL（比如 https://www.tpkele.com/en/resources）
3. 点击 "请求编入索引"
4. 每天最多可以提交 10-15 个 URL

优先提交顺序（如果手动提交）：
-------------------------------
1. 先提交主 Resources 页: /en/resources, /ru/resources
2. 再提交主 Projects 页: /en/projects, /ru/projects
3. 然后提交 Zimbabwe 项目详情页
4. 最后提交各个 Resources 子页面
